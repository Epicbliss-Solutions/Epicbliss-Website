Power BI App Help

Power BI App Help - Epicbliss Solutions LLP

1. Overview

This Power BI App offers a pre-built, interactive report designed to help users visualize and analyze their business data more effectively. It can be tailored to work with various data sources and is ideal for teams looking to streamline decision-making through dashboards and analytics.

2. Installation Instructions

Option A: Install from Microsoft AppSource

  1. Go to Microsoft AppSource.
  2. Search for the app by name.
  3. Click Get It Now and follow the login process.
  4. The app will be added to your Power BI workspace automatically.

Option B: Import the .pbix file manually

  1. Download the .pbix file from the official download link or email (if provided).
  2. Open the file using Power BI Desktop.
  3. Review and make any desired changes.
  4. Publish it to Power BI Service if needed.

3. Configuration Steps

A. Connect to Your Data Source

  1. Go to the workspace where the app was installed.
  2. Open the dataset settings and select Data source credentials.
  3. Click Edit Credentials and choose the appropriate authentication method (OAuth2, Basic, etc.).
  4. Sign in and save the connection.

B. Set Parameters (if applicable)

  1. In the dataset settings, locate the Parameters section.
  2. Input any required parameters such as:
    • API keys
    • Database or server names
    • Regional or client-specific filters
  3. Click Apply to save your changes.

4. Frequently Asked Questions (FAQ)

Q1: Why is my data not loading?
A: Ensure that your data source credentials are entered correctly and that the parameters match your environment.

Q2: Can I customize this app?
A: Yes. You can make a copy of the report and edit it using Power BI Desktop or within the Power BI Service.

Q3: I’m getting a refresh error. What should I do?
A: Confirm that all credentials and parameter values are correct. Also check your gateway settings if applicable.
